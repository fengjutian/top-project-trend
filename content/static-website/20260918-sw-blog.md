## [rlhfbook](https://rlhfbook.com/)

RLHF Book 是一本系统讲解 RLHF（人类反馈强化学习）和 LLM 后训练（Post-Training） 的在线技术书籍。

内容从 SFT（监督微调） 开始，逐步介绍 Reward Model、RLHF、PPO、DPO 等训练方法，并进一步涉及 Preference Learning、奖励建模、推理模型训练、模型评估等内容。

它的特点是理论结合工程实践，不仅解释算法原理，还关注训练流程、数据构建和实际实现。

简单理解：RLHF Book = 一份从 SFT → 偏好学习 → RLHF → LLM 后训练的系统学习路线。

## [system-design-notes](https://github.com/liquidslr/system-design-notes)

system-design-notes 是一个整理《System Design Interview – An Insider’s Guide》的开源学习笔记项目，主要帮助开发者系统学习大型系统设计。

内容涵盖 API 设计、数据库、缓存、消息队列、负载均衡、分布式系统、限流、数据一致性、扩展性等核心知识，并通过 URL Shortener、YouTube、Twitter 等典型案例讲解系统设计思路。

简单来说：把系统设计面试中的核心知识和经典案例整理成一套可快速复习、实践的技术笔记。
